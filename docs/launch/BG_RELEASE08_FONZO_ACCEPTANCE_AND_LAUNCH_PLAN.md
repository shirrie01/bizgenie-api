**Status vocabulary.** `OFFLINE TESTED` = automated tests pass in CI with doubles/stubs. `SOURCE COMPLETE` = code exists, wired, but the relevant path is not covered end-to-end offline. `HOSTED VERIFIED` = observed on hosted staging with founder-supplied evidence in #191. `BLOCKED` = cannot proceed without an external action or a founder decision (named). A row can carry one state per layer.
