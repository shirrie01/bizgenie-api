Both still created no asset, but are now classified 503. This changes the API image: the accepted E1 image does not include it. It has no safety effect, so I recommend carrying it in the next image build rather than rebuilding E1.
**Founder execution packet for hosted E4 acceptance (future; nothing run):**

2. Mirror `clamav/clamav:1.4.7` by index digest `sha256:ac15046e…d62d` into the existing registry; record `CLAMAV_REF` (runbook §7).
3. `a2-scanner-gate.sh pre` (clamd must answer `VERSION` with a database ≤ 72 h, then the five-check probe: clean, EICAR, 32 MiB, stale-guard, unreachable).
