### Cost model — rejected generations count

For a commercial with K accepted shots, let Cj be the verified all-in provider/observation cost per attempt for shot j, Nj its actual number of attempts including rejected takes, and R be deterministic editing/rendering/storage/licensing cost. Then:

    actual finished cost = sum(Nj * Cj for j=1..K) + R

Before empirical results, a numerical expected usable cost is not evidenced. If an acceptance probability qj is later measured and a stationary independent-attempt model is justified, the rough expected provider component is sum(Cj/qj), not simply sum(Cj). Report the actual observed acceptance rate and all failed takes, not a hypothetical perfect first pass. For the same C, two paid takes for one accepted shot cost2C; four take4C. There is no approved measured rejection rate yet.

Pre-approve finite per-shot attempts and a total commercial budget including every rejection/observation/render operation before any expanded pilot. Automatic retry/regeneration remains OFF.
