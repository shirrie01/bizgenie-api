# BG-STUDIO-021 — customer media intake

26 October2026. Local/disposable PostgreSQL and mock storage/inspection only. Disabled by default; no live uploads, scanner, bucket or IAM change.

New customer_media_intakes quarantines metadata/bytes and immutable attestation before creating any selectable media_assets record. Existing private storage/media records remain the promoted reference architecture. Owner-only writes; scoped member reads. Initiation is idempotent and captures server rights-policy version/statement/time plus customer attestation, **not verified ownership**. No external URL, customer bucket/key or signed URL is accepted/returned.

Routes under /customer/assets: POST /uploads JSON {tenant_id,project_id,brand_id,filename,content_type,bytes,rights_confirmed:true,idempotency_key};201 metadata + authenticated upload_path. PUT /uploads/:id/bytes?scope raw declared MIME, max32MiB; authorization before body parsing, exact size and PNG/JPEG/WebP/MP4 signature checks; immutable create-only private key with generation-pinned recovery after lost storage acknowledgement. POST /:id/complete {scope}: pinned bounded read + sha256-bound mandatory inspection, then recheck ownership/state/generation and promote reference row atomically with audit. GET /?scope&limit<=100&cursor returns ready active selections; GET /:id metadata; GET /:id/preview authenticated pinned bytes; POST /:id/revoke {scope}; DELETE /:id?scope tombstones and denies delivery/selection.

States initiated/quarantined/ready/rejected/revoked/deleted. Quarantine is never selectable/deliverable. Scan output must match exact digest/MIME and include engine/policy, verdict/dimensions/duration;12-second boundary and cancellation signal, trusted inspector must honor cancellation. Media read10-second/declared-byte ceiling; preview also pins inspection's storage generation. Pending initiations are bounded across instances under a scope advisory lock (default20 per project), not represented as a global storage-spend/rate cap. No automatic destructive purge: deleted means physical deletion pending approved retention/backups policy.

Default composition returns503 MEDIA_INTAKE_UNAVAILABLE. Enabling requires explicit server injection of storage, inspector, rights policy and enabled:true; no existing capability flag turns it on.
